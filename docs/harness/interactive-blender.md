Main-thread application timers process all commands; no Blender Python background thread is introduced.

This is a **different execution environment**, not a claim that Windows background isolation extends to GUI work. The operator must explicitly select `COCREATE_INTERACTIVE_BLENDER=linux-xvfb-v1` and provide a dedicated 2 GiB/64-task delegated leaf beneath a 3 GiB parent. Default app/browser bootstrap retains its existing 1 GiB parent/512 MiB browser limits. The desktop job has a 60-second aggregate CPU budget, 600-second wall bound, 8 MiB monitored private files/single-file ceiling and 64 MiB protocol ceiling. The stopped launcher is attached before any X/Blender code runs; parent death, cancellation or resource failure kills the entire group before cleanup. Software rendering, private-display/file/network/credential denial, real frame and effective geometry input must pass **native CI** before integrating/enabling the companion transport.
