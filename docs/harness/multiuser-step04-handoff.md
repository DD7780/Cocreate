Windows launches a unique zero-capability AppContainer, explicitly restricts inherited handles and assigns the suspended child to a Job Object before resume. Limits: one process, 512 MiB committed process/job memory, 10 CPU seconds, 20 seconds wall, 128 MiB JavaScript heap, 4 MiB serialized input/output and 16 KiB captured stderr. Only compiler assets and that job input receive explicit read grants. Node permissions additionally deny writes, child processes, workers, addons/WASI and reads outside runtime/job. Windows standard shared OS resources are governed by AppContainer ACLs; do not infer denial of every Windows-readable public file from the private-file test. The explicit environment contains only bootstrap profile/system paths, NODE_ENV and UV_THREADPOOL_SIZE; Windows may add profile TEMP/TMP. It excludes application/provider/deployment secrets and Node injection flags.

Coordinator AbortSignal reaches the tool/worker. Kill-on-close plus the native parent/watchdog/cancel checks terminate child work; the parent waits for launcher closure and cleans its UUID job directory and AppContainer profile. Cancellation, CPU/memory/output failures and timeout checks assert PID disappearance and no remaining job files. Unavailable isolation rejects explicitly, retains the prior artifact and never chooses a host compiler. Actual OS preflight precedes builder dispatch; infrastructure/resource failures stop without provider repairs. Explicit replay adds no inference. Operator repair followed by explicit retry is required; failed preparation/preflight promises reset so repair can be retried.

Implementation references: [Microsoft AppContainer](https://learn.microsoft.com/en-us/windows/win32/secauthz/implementing-an-appcontainer), [Job Object limits](https://learn.microsoft.com/en-us/windows/win32/api/winnt/ns-winnt-jobobject_extended_limit_information), [Node 22 permissions](https://nodejs.org/docs/latest-v22.x/api/permissions.html), [esbuild browser API](https://esbuild.github.io/api/#browser) and [Bubblewrap](https://github.com/containers/bubblewrap).
