## Outcome and responsible boundary

The existing private Storage bucket and an unused ZIP reservation/upload/finalization method already existed. Active promotion instead persisted the current six inline versions/checkpoint in canonical JSON, and event projection export carried references without bytes. Empty-cache hydration could not recover older bodies. Step 01's projection-only gap observation remains correct for that primitive; Step 03 adds the necessary archive path around it.

The active path now publishes deterministic product/checkpoint envelopes to private `<projectId>/bodies/<sha256>` objects with immutable uploads. Uploaded or already-existing bodies are read back and verified before publication is considered successful; verified immutable publications are memoized per process. Canonical `harness_state` stores schema version 1, hash/byte-length/MIME descriptors and permanent version metadata/history using the existing coordinator-fenced snapshot RPC. The compatibility ZIP `artifact_versions` table/method remains unused by this active pipeline. No dependency change, new SQL migration or historical migration was needed.

Promotion publishes the candidate body first, then rechecks ownership, controller and frozen revision/fingerprint. Until canonical commit, pending candidates are excluded from latest/history/preview and concurrent autosaves wait. Commit or synchronous publication failure clears the gate and restores the previous product; later edits remain saved. Loss after upload cannot promote or issue another physical attempt. Archived version IDs never get reused after a retained-product rollback. Interrupted publication can leave private orphan objects, which replay verifies and reuses; no automatic cleanup occurs.

Opening materializes and validates the current six version bodies and relevant checkpoint before hydration. Verified bytes populate an empty derived cache; older version and other non-workspace event bodies load lazily from the project manifest. SHA-256, byte length, project/kind/version identity and source paths/content are checked. Legacy partial source archives remain readable without claiming they compile. Current membership/coordinator authority is rechecked after an awaited historical read before returning preview/ZIP bytes. No public bucket, URL or signed download URL is created. Missing/corrupt/unavailable required bodies fail explicitly with `409 artifact_unavailable`, distinct from an empty project, and never start inference.
