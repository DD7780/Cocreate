# Canvas writing surface

## Requested outcome and boundaries

Accepted 2026-10-15 from the user's explicit request: simplify Canvas into a clean, spacious writing surface. Remove the right-hand Shared context sidebar from Canvas (Shared Intent revision selector, Accepted requirements, View requirements, Recorded usage, workflow stage and anything else inside it) together with its reserved grid column. The editor fills the available width and height with responsive margins, typing starts near the top-left, and a subtle inline placeholder replaces the large “START WRITING / Click anywhere on the canvas to begin” box. Clicking blank writing-surface space focuses the editor; the surface grows with content and scrolls vertically. Recorded usage remains in Workflow.

Scope: UI only. Allowed files: `src/App.tsx` (Canvas mount and blank-space focus), `src/styles.css` and `src/studio-ivory.css` (Canvas selectors), the Canvas assertions in `scripts/verify-reliability.ts`, the new `scripts/verify-canvas-surface.ts` browser check, its evidence under `artifacts/canvas-writing-surface/`, the prepared release fingerprint in `wrangler.jsonc` and affected canonical harness documents. No server, `shared/` contract, storage, migration, provider or deployment change.

Retained: `AgentPanel`, its revision selector, IntentReview drawer, usage card and their Artifacts mount stay available as reusable views; only the Canvas entry point is removed. Requirements, accepted revisions, attribution, history, usage records and every HTTP/WebSocket contract are unchanged; no stored history is deleted and workflow authority is unaffected. Collaboration/presence carets, device/server save statuses, the formatting toolbar, split view, and the Build my changes button and editor-focused Alt+X submission are retained. Typing, clicking and focusing remain inference-free.

## Evidence and contracts

Graphify query (“Canvas Shared context sidebar editor Accepted requirements Recorded usage”) located `src/App.tsx`, `src/workspace/AgentPanel.tsx`, `BuildAccounting.tsx` and the presentation notes in architecture/product/decisions. Source inspection: `Workspace` mounted `AgentPanel` beside `EditorContent` inside `.document-layout`, and a second time in `.artifacts-layout`. The empty-state box is a `::before` pseudo-element on `.document-editor` in both stylesheets; it is not a component. `scripts/verify-reliability.ts` exercised the sidebar on Canvas; those checks move to the Artifacts mount and Canvas gains a no-sidebar assertion. `scripts/verify-workflow-overview.ts` already asserts that Workflow has no `.agent-panel`.

Blank-space focus maps the click to the nearest document position (clamped into the editor's bounds) through ProseMirror `posAtCoords`; controls and existing editor clicks are left to their native handling. The submission shortcut listener remains attached to the editor root, so focus via blank space keeps Alt+X editor-scoped.
